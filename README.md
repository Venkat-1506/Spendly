# Spendly - Smart Expense Tracker for Indians 🚀

Spendly is a modern SaaS-style expense management platform built specifically for Indian users. It helps individuals and teams track expenses, manage budgets, analyze spending habits, achieve financial goals, and gain AI-powered financial insights — all through a beautiful and responsive dashboard experience.

---

## ✨ Features

### 📊 Expense Management

* Real-time expense tracking
* Category-based expense organization
* Budget planning & monitoring
* Spending analytics dashboard

### 🤖 AI-Powered Insights

* Smart spending analysis
* Personalized savings recommendations
* Financial intelligence dashboard
* Expense trend monitoring

### 🎯 Financial Goals

* Goal creation & tracking
* Progress visualization
* Savings milestone management
* Goal completion insights

### 📈 Reports & Analytics

* Interactive charts using Chart.js
* Spending pattern analysis
* Monthly & category-wise reports
* Financial summaries

* Shared expense tracking

* Login & signup pages
